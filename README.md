# Engineering portfolio starter

## Preview
Open `index.html` in a browser. No installation or build process required.

## Update your profile
Open `content.js` in a text editor. Change `name`, `email`, `bio`, and `portrait`.

## Add photos
Copy images into `images/` (you can make subfolders). Set `cover: 'images/project-cover.jpg'` and gallery entries such as `{image: 'images/detail.jpg', caption: 'What this shows.'}`. A blank image path displays a placeholder.

## Add a project
Copy one complete object in the `projects` array in `content.js`, paste it after another project separated by a comma, and update its unique `slug`, title, category, summary, cover, description, and gallery. The home-page card and individual project page appear automatically.

## Publish for free
Upload these files to a GitHub repository and enable GitHub Pages (Settings → Pages → Deploy from a branch → main / root). Or drag the entire folder into Netlify Drop. No database or paid hosting required for a static portfolio.

## Notes
The three initial projects are illustrative drafts, not final project documentation. Replace wording and photos with your approved public materials. Do not publish confidential employer, client, or sponsor information without permission.
